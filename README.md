# 📸 Foto Studio Monty

Sitio web desarrollado por **Dreams Multimedia** como proyecto grupal durante **tercer año de Bachillerato Técnico en Desarrollo de Software**.

El proyecto fue realizado para **Foto Studio Monty**, con el objetivo de crear un sitio web para presentar información del negocio, productos, servicios y diferentes opciones disponibles para sus clientes.

## 🌐 Sitio web

🔗 **[[Ver sitio web](https://fotostudiomonty.unaux.com/)](#)**

> El enlace será agregado cuando el sitio sea publicado.

## 📋 Características

- 🏠 Página de inicio
- 🛍️ Catálogo y tienda
- 🔎 Detalle de productos
- 📍 Información de ubicación
- 🏢 Información sobre el estudio
- 🎓 Paquetes para diferentes niveles educativos
- 🖼️ Imágenes y contenido visual
- 📱 Diseño adaptable

## 🛠️ Tecnologías utilizadas
